# MusicFlow Cinema LAB — отдельный тестовый кинораздел

**Статус:** экспериментальная ветка. Официальный релиз MusicFlow 0.7.40 и все Pro-ветки НЕ изменяются.

## Установка
Скачайте APK из GitHub Actions workflow **Build MusicFlow Cinema LAB TEST APK**, артефакт `MusicFlow-Cinema-LAB-TEST-apk`. Пакет `com.musicflow.preview.cinematest` отличается от официального `com.musicflow.preview`. Ярлык: **MusicFlow Кино TEST**. Подпись — отладочная, предназначенная только для испытания. Оригинальный ключ подписи не используется.

По умолчанию тестовая сборка открывает самостоятельный раздел **Кино TEST**. Остальные функции MusicFlow присутствуют, но оригинальное приложение не заменяется и его данные не изменяются. Автообновления из официального канала в тестовом пакете отключены.

## Функции
- Кино: карточки, поиск, фильтр «Фильмы / Сериалы», избранное, «Смотреть позже», история и восстановление позиции.
- 4 тестовых открытых короткометражных фильма Blender Foundation, а также подборка с выбором трёх серий, воспроизводятся штатным **Media3 ExoPlayer**, если доступен внешний сервер видео.
- Поиск **TVMaze** возвращает метаданные сериалов; он НЕ предоставляет видео/подписки. Такие карточки честно показывают «Только сведения». TVMaze attribution обязательна.
- Подключение сторонних источников по URL из меню **Кино → ⚙ → Вставить ссылку → Подключить**.
- Можно вставить заранее подготовленный тестовый JSON-плагин одной кнопкой.

## Формат стороннего плагина

Плагин в этом прототипе — **JSON-манифест**, а не исполняемый JS.

```json
{
  "format": "musicflow.cinema.v1",
  "name": "Мой легальный киноисточник",
  "catalog_url": "https://example.org/cinema/catalog.json"
}
```

Каталог — JSON такого вида:

```json
{
  "items": [
    {
      "id": "film-1",
      "title": "Демо-фильм",
      "type": "movie",
      "year": 2020,
      "genre": "Документальный",
      "description": "Описание",
      "poster": "https://example.org/poster.jpg",
      "stream_url": "https://example.org/film.mp4",
      "attribution": "© Автор, лицензия на показ"
    },
    {
      "id": "series-1",
      "title": "Демо-сериал",
      "type": "series",
      "episodes": [
        { "id": "s1e1", "title": "1 серия", "stream_url": "https://example.org/episode.m3u8" }
      ]
    }
  ]
}
```

Работающие демонстрационные файлы:
- Manifest: `https://raw.githubusercontent.com/smoc1983-web/MusicFlow-/feature/musicflow-cinema-lab-20261122/cinema-test/demo-plugin.json`
- Catalog: `https://raw.githubusercontent.com/smoc1983-web/MusicFlow-/feature/musicflow-cinema-lab-20261122/cinema-test/catalog.json`

Поддерживаются HTTPS MP4 и HLS с разрешёнными потоками, если конкретный формат совместим с Media3. Нет поддержки DRM-декодирования без лицензий.

## Отношение к плагинам Lampa

Lampa-плагины вроде `http://bwa.ad/rc` — JavaScript, который опирается на API Lampa (`window.Lampa`). **В тестовой MusicFlow нет интерпретатора или рантайма Lampa, поэтому вставка таких ссылок выдаёт понятную ошибку, а не якобы успешное подключение.** Это сознательное ограничение безопасности. Для совместимости понадобился бы отдельный полноценный адаптер, на этом этапе его нет.

Источники JSON добавляются и удаляются только пользователем. Никакие внешние JS или APK не исполняются. Доступны только HTTPS-адреса публичных хостов, для манифестов и каталогов перенаправления отключены. Ограничены размер и количество сущностей. Никакого обхода DRM, платёжных функций, скачивания чужого контента или распространения закрытых источников.

## Границы теста
- Тестовый APK не является официальным релизом и не должен появляться в основном канале GitHub Releases.
- Финальную подпись оригинальным ключом и официальный выпуск можно сделать **после проверки пользователя и отдельного разрешения**.
- История, избранное и позиция воспроизведения тестовой версии изолированы от основного MusicFlow.
- Не гарантируется доступность внешних потоков или метаданных в конкретной сети.
- **Рекомендуемые проверки на Samsung S24:** запуск рядом с основной версией; открытие «Кино TEST»; воспроизведение 2–3 демо-фильмов; выбор серии; поиск по названию, избранное, «Смотреть позже», закрытие/возврат; подключение тестового JSON; отказ в подключении `http://bwa.ad/rc`.

Это этап испытаний с упором на безопасность данных и совместимость. Производственную ветку и Pro не трогать.
