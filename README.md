# MusicFlow — музыкальный плеер, радио и IPTV для Android

**Последний официальный APK:** [MusicFlow 0.7.37](https://github.com/smoc1983-web/MusicFlow-/releases/tag/v0.7.37). Устанавливается поверх 0.7.35 с сохранением данных и исходной подписи.

## Изменения в 0.7.37
- «ТОП песен» перенесён на главный экран рядом с «Популярное» и «Новинки»; заголовок «Музыкальная лента» удалён.
- Россия — места из чарта Яндекс Музыки по данным UpSound AI: сумма дневных слушателей за доступные дни, не количество воспроизведений. Архив годового периода пока неполный.
- Мир — статистика ListenBrainz: зарегистрированные прослушивания пользователей сервиса, не всего музыкального рынка.
- Для обоих источников — переключатели Неделя / Месяц / Год, обложки при наличии и поиск доступной записи в подключённых музыкальных источниках.
- Сохранены исправление прокрутки результатов поиска, удаление нижней кнопки «Другой источник» и автоматические запасные потоки плеера.
- Официальный APK проверен и подписан неизменным сертификатом; обновление доступно через «О приложении» → «Проверить обновления».

## Изменения 0.7.37 (до публикации)
- В ТОПе песен весь выбранный российский или мировой чарт открывается как единая очередь воспроизведения, а не отдельная композиция.
- Кнопки Назад/Далее и автопереход работают внутри этого чарта. Источник каждого следующего трека ищется по запросу только во время проигрывания.
- Невоспроизводимые треки пропускаются механизмом восстановления; границы чарта не подменяются случайным альбомом.
- Очередь сохраняется после перезапуска. Подпись прежнего официального сертификата обязательна.

## Функции
- Поиск записей Zaycev, Muzofond, Mail.ru; объединение источников, подтверждённые альбомы и обложки.
- Фоновый Media3/ExoPlayer, мини- и полноэкранный плеер, очередь, повтор, перемешивание, автопереход на запасные потоки.
- Избранное, история, восстановление очереди/позиций, синхронизированные тексты LRCLIB.
- Отдельное российское интернет-радио: поиск станций, избранное, воспроизведение онлайн.
- IPTV: RuVideoHub, собственные плейлисты M3U/M3U8, полноэкранное воспроизведение.
- Пятиполосный эквалайзер, звуковые пресеты, опциональное усиление тихих записей.
- Проверка и установка подписанных APK через GitHub Releases, темы, диагностика и поддержка разработчика.

## Улучшения, тестируемые в ветках 0.7.31–0.7.34
- **Таймер сна** с пресетами 10, 15, 20, 30, 45 и 60 минут, обратным отсчётом и остановкой звука без сброса очереди.
- **Коррекция времени текстов** на ±5 секунд с шагом 250 мс; настройка сохраняется.
- Реальные Kotlin/JUnit unit-тесты, правило дисциплины разработки **ub-mode** в [AGENTS.md](AGENTS.md) и [.agents/skills/ub-mode/SKILL.md](.agents/skills/ub-mode/SKILL.md).

## Функции из 0.7.33, включённые в 0.7.34 — фоновый плеер и восстановление

- В полноэкранном музыкальном плеере **стрелка вниз** и **свайп вниз** возвращают к приложению, не прерывая музыку и не сбрасывая очередь.
- **«Сейчас играет»** в верхней панели открывает текущую песню и при воспроизведении, и на паузе. Мини-плеер остаётся доступным.
- Для записей без известной длительности сохраняется позиция, если Media3 ранее подтвердил возможность перемотки. После запуска позиция восстанавливается **только при подготовленной перематываемой дорожке**.
- Радио, телевизионный эфир, устаревший VK и неподтверждённые неперематываемые потоки не восстанавливаются произвольной перемоткой.
- Фоновый сервис теперь использует Media3 Wake Mode для воспроизведения с погашенным экраном; при остановке/паузе блокировки отпускаются.
- **Тесты:** ускоренная модель 6 часов в Kotlin/JUnit, реальный эмулятор Android 35 с MediaSessionService, локальным WAV и 130-секундным экраном в спящем режиме.
- Реальный прогон на Samsung S24 не заявляется как выполненный: его нужно провести после установки совместимо подписанной сборки.

## Проекты, лицензии и источники
- [SimpMusic](https://github.com/maxrave-dev/SimpMusic) — GPL-3.0, идейный пример UI/UX и функций. **Исходный код SimpMusic и его YouTube Music scraper не включены в MusicFlow.**
- [ub-mode](https://github.com/unclebob/ub-mode) — MIT; копия навыка и лицензии размещена в репозитории.
- VK, Audius и Jamendo по запросу владельца исключены из общего поиска.
- Официальный package ID `com.musicflow.preview`; при релизах сохранять постоянный сертификат подписи.
- Google Play Protect — внешняя системная проверка, прохождение CI не гарантирует отсутствия предупреждения.

См. [аудит внедрения](SIMPMUSIC_UB_MODE_AUDIT_RU.md).

## Новое в 0.7.32 (не опубликовано)
- История пополняется только после подтверждённого прослушивания (не от простого открытия записи).
- Локальная статистика: приблизительное подтверждённое время, количество запусков и до 200 самых прослушиваемых музыкальных и радиозаписей. Старую историю программа не пересчитывает.
- Паузы, переключение, скачки позиции при перемотке и фоновое ожидание не накручивают статистику.
- JSON очереди записывается только при изменении Media3 timeline, а позиция сохраняется отдельно.
- В разделе истории есть вкладка «Статистика» и отдельное управление очисткой данных.
- **ub-mode**: перед реализацией пройден красный TDD-тест. Результаты итогового CI фиксируются в журнале разработки.
- Исходный код GPL-3.0 SimpMusic в MusicFlow не переносился.
