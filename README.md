# MusicFlow v0.7.9 Preview — три музыкальных источника

## Реальное воспроизведение Zaycev.net

- Третий самостоятельный источник в **едином музыкальном поиске**: Muzofond, Mail.ru и Zaycev без выбора источника пользователем.
- Для Zaycev используется публичное поисковое API сайта: `GET https://zaycev.net/api/external/pages/search/tracks` с `q`, `page`, `limit`. Сайт отвечает `trackIds` и `tracksInfo`.
- Выбранная песня имеет внутренний идентификатор `zaycev://track/<id>`. При воспроизведении `ResolvingDataSource` Media3 запрашивает:
  1. `POST /api/external/track/filezmeta` — временный идентификатор `streaming`.
  2. `GET /api/external/track/play/<hash>` — прямой адрес `https://dl.zaycev.net/...`.
  3. Media3 загружает MP3 с CDN. Браузер или WebView не используются.
- Проверено 20 ноября 2026 в GitHub Actions: публичные endpoint ответили HTTP 200, MP3 ответил HTTP 206 с `audio/mpeg`.
- Ссылки на аудиофайлы ограничены сроком действия и обновляются по запросу; в избранном хранится стабильный идентификатор, не временная ссылка.
- Прямое воспроизведение работает только для `playbackEnabled=true`; региональные ограничения или изменение сайта могут препятствовать запуску. Перенаправления к другим сайтам, обход логина и платных функций не реализованы.

## Улучшения альбомов

- В списке треков альбома воспроизводимая песня подсвечена, подписана «♫ Сейчас играет» или «♫ На паузе».
- Аналогичная индикация в общем списке поиска/избранного.
- После нового поиска и группировки песен по альбомам список возвращается к началу.
- Запуск из треклиста сначала повторно использует известные источнику и доступные аудиопотоки. При отсутствии подходящей ссылки выполняет фоновый поиск по трём музыкальным каталогам; неподтверждённый поток не запускает.
- iTunes и Deezer используются только для информации об альбомах, не для скачивания или прослушивания.

## Сохранённые функции

- Рекомендации и сборники Zaycev наверху главной, обложки, альбомный плеер, IPTV с файлами M3U/M3U8, fullscreen, поиск качества, экспорт логов.
- Audius удалён.
- Версия: `0.7.9-preview`, отдельный package `com.musicflow.zaycev79preview`. Предыдущая v0.7.8 сохранена в `stable/v0.7.8-preview`.
