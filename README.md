# MusicFlow · Android-плеер

**Текущий статус:** версия 0.7.30 готовится в отдельной ветке. Новое обновление **ещё не опубликовано** — сначала предоставляется отчёт о проверках и полезных функциях Meridius.

## Музыка и поиск
- Общий поиск: Zaycev, Muzofond и Mail.ru Music, без VK.
- Доступные потоки воспроизводятся в штатном Media3/ExoPlayer.
- Поиск по исполнителю и названию, альбомная группировка и обложки.
- Избранное, IPTV, музыкальная очередь, мини- и полноэкранный плеер.
- Проверка и установка подписанных официальных APK через MusicFlow.

## Звук — новые функции на основе идеи Meridius

- **Нативный эквалайзер Android**: пять удобных регуляторов частот, которые интерполируются на реальные полосы устройства.
- Пресеты: нейтральный, басы, вокал, рок и высокие; можно настроить звук самостоятельно.
- **Опциональное усиление тихого звука** до +3 дБ через Android LoudnessEnhancer. Это ограниченное фиксированное усиление, **не** автоматическая нормализация громкости и не кроссфейд.
- Настройки сохраняются; аудиоэффекты работают на аудиосессии штатного ExoPlayer. Оба улучшения по умолчанию выключены и могут быть недоступны для некоторых устройств/выходов.

Исходный Meridius — проприетарное Windows/Linux-приложение с закрытым кодом. Новые функции реализованы самостоятельно на стандартных Android API, без копирования кода или подключения VK.

## Кандидаты для следующего этапа поиска

- **Audius**: https://api.audius.co/v1 — открытый API треков/потоков.
- **Jamendo**: https://developer.jamendo.com/v3.0/tracks — независимая музыка и фильтр языка `ru`, нужен ключ.
- **Openverse**: https://api.openverse.org/v1/ — открыто лицензированные записи и атрибуция.
- **Internet Archive**: https://archive.org/advancedsearch.php — архивное аудио, проверить права.
- **Radio Browser**: https://api.radio-browser.info/ — станции, не отдельные песни.

Эти источники пока не добавлены: необходимо проверить реальные русскоязычные результаты, доступность потоков и лицензии.

## Play Protect и обновления

- Android Package ID: `com.musicflow.preview`; новая версия `0.7.30`, код `729`.
- Стабильный ключ для релизов — тот же, что у официальной MusicFlow 0.7.28. Отладочные версии не заменяют стабильные.
- Play Protect — системная проверка Google. Приложение не может самостоятельно скрыть её предупреждение; отсутствие вирусов нельзя гарантировать исходным статическим тестом.
- Отчёт о разрешениях и рисках: `PLAY_PROTECT_AUDIT_RU.md`.
