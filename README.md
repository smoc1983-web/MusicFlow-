# MusicFlow — музыкальный плеер, радио и IPTV для Android

**Последний опубликованный APK:** [0.7.30](https://github.com/smoc1983-web/MusicFlow-/releases/tag/v0.7.30). **0.7.31 — в разработке**, не опубликован.

## Функции
- Поиск записей Zaycev, Muzofond, Mail.ru; объединение источников, подтверждённые альбомы и обложки.
- Фоновый Media3/ExoPlayer, мини- и полноэкранный плеер, очередь, повтор, перемешивание, автопереход на запасные потоки.
- Избранное, история, восстановление очереди/позиций, синхронизированные тексты LRCLIB.
- Отдельное российское интернет-радио: поиск станций, избранное, воспроизведение онлайн.
- IPTV: RuVideoHub, собственные плейлисты M3U/M3U8, полноэкранное воспроизведение.
- Пятиполосный эквалайзер, звуковые пресеты, опциональное усиление тихих записей.
- Проверка и установка подписанных APK через GitHub Releases, темы, диагностика и поддержка разработчика.

## Улучшения, которые тестируются в 0.7.31
- **Таймер сна** с пресетами 10, 15, 20, 30, 45 и 60 минут, обратным отсчётом и остановкой звука без сброса очереди.
- **Коррекция времени текстов** на ±5 секунд с шагом 250 мс; настройка сохраняется.
- Реальные Kotlin/JUnit unit-тесты, правило дисциплины разработки **ub-mode** в [AGENTS.md](AGENTS.md) и [.agents/skills/ub-mode/SKILL.md](.agents/skills/ub-mode/SKILL.md).

## Проекты, лицензии и источники
- [SimpMusic](https://github.com/maxrave-dev/SimpMusic) — GPL-3.0, идейный пример UI/UX и функций. **Исходный код SimpMusic и его YouTube Music scraper не включены в MusicFlow.**
- [ub-mode](https://github.com/unclebob/ub-mode) — MIT; копия навыка и лицензии размещена в репозитории.
- VK, Audius и Jamendo по запросу владельца исключены из общего поиска.
- Официальный package ID `com.musicflow.preview`; при релизах сохранять постоянный сертификат подписи.
- Google Play Protect — внешняя системная проверка, прохождение CI не гарантирует отсутствия предупреждения.
