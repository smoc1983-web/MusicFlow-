# Cinema TEST v8 — Native library

Статус: самостоятельный Android-APK для испытания, **без обновления основной MusicFlow и Pro**.

## Экран
Тёмный киноинтерфейс: крупная обложка рекомендуемого фильма, горизонтальные подборки, компактные карточки, категории «Главная», «Фильмы», «Сериалы», «Жанры», «По годам», «По странам», «Избранное». На основной витрине нет маркировки названия внешнего видеосервиса; права на контент остаются у соответствующих правообладателей. Источник продолжает быть техническим сетевым провайдером. Сведения об источнике и его URL не фальсифицируются.

## Поиск
Строка «Название фильма или сериала» обращается к публичному API поиска видеосервиса; если API выдаёт пустой ответ, ищет в доступных категориях по названиям и описаниям. Поиск не обещает находить абсолютно все видео сайта, особенно закрытые или неиндексируемые.

## Сериалы
Для серии открывается метадата, затем публичная связь с телешоу и список сезонов. После выбора сезона можно просматривать серии, отсортированные по номеру. Каждая выбранная серия отдельно разрешается в доступный HLS-поток перед запуском Media3. Для отдельных видео без привязки к сериалу меню сезонов недоступно.

## Видеоплеер
Собственный встроенный Android Media3 ExoPlayer, кнопка разворачивания с полноэкранным режимом, автоматическая/ручная смена видеодорожки в соответствии с доступными качествами HLS. Если в источнике только один профиль или его качество неизвестно, программа не выдумывает варианты. Прогресс воспроизведения сохраняется.

## Техническая архитектура
Вместо ненадёжных fallback-заголовков HTML используется публичный API доступных фильмов, категорий и метаданных. Из API карточек берутся реальные названия, thumbnail, description. Для жанров запрашиваются отдельные curated-ленты. Поддержка пользовательских HTTPS/JSON/M3U ссылок из предыдущих тестов сохраняется, JavaScript-плагины не запускаются. Все списки без скрытых платных видео, никакого обхода авторизации, DRM или подписок.

## Испытание
1. Установить test APK отдельным пакетом `com.musicflow.preview.cinematest8`.
2. Проверить афишу, вкладки жанров и поиск названия фильма, сравнить заголовки/постеры с сайтом.
3. Проверить отдельную серию и переход к выбору сезонов и других серий.
4. Начать видео → «На весь экран» → выйти обратно без потери позиции.
5. Если HLS предлагает несколько качеств, выбрать 480p/720p/1080p, проверить реальное переключение.
6. Проверить избранное, сохранение добавленных ссылок и отсутствие влияния на основную MusicFlow.

Проверка на физическом устройстве и все возможные форматы медиа — отдельный этап; успешная компиляция не гарантирует работоспособности стороннего сервиса.
