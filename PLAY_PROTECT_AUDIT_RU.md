# MusicFlow — аудит Google Play Protect

Проверено по исходникам MusicFlow 0.7.29. Это **не официальный результат проверки Google Play Protect**, и предупреждение в Android всё ещё может появляться.

## Проверено
- Package ID `com.musicflow.preview`, `versionCode 729` для будущей совместимой сборки.
- Android Manifest запрашивает только INTERNET, ACCESS_NETWORK_STATE, REQUEST_INSTALL_PACKAGES, FOREGROUND_SERVICE и FOREGROUND_SERVICE_MEDIA_PLAYBACK.
- Нет разрешений на контакты, микрофон, SMS, местоположение, доступность или установку APK без подтверждения.
- Встроенное обновление скачивает APK, проверяет новую версию, package ID и цифровой сертификат; финальное решение об установке принимает Android Package Installer.
- Музыкальная авторизация удалённого источника, ввод его токена и обращения к его API убраны из нового кода. Сохранённые токены и Keystore alias удаляются при запуске.
- Эквалайзер и усиление используют системные AudioEffect без дополнительных разрешений, действуют только в сессии MusicFlow.

## Оставшиеся вопросы
- `android:usesCleartextTraffic="true"` сохранён для пользовательских IPTV-ссылок `http://`. Незашифрованный поток может быть модифицирован по пути. Полный запрет HTTP может сломать пользовательские списки.
- Загрузка медиа со сторонних сайтов допускает изменение доступности и условий использования. Нужно отдельно проверять лицензии, цепочки редиректов и корректность обработки URL.
- Нельзя подтвердить реальные результаты на Android 17/Samsung S24 без установки и проверки Play Protect на устройстве.

## Как работать с предупреждением
1. Проверить подпись официального APK через `apksigner verify --print-certs`; сравнить сертификат с 0.7.28.
2. Проверить список разрешений собранного APK через `aapt dump badging`.
3. Провести сканирование установленного приложения Play Protect на тестовом Android.
4. Для предупреждения о неизвестном разработчике направить обоснованное обращение в Google, а не отключать защиту.
5. Для Google Play следует отдельно проверить допустимость `REQUEST_INSTALL_PACKAGES` и правила магазинов.
