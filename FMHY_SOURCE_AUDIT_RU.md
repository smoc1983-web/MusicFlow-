# FMHY → MusicFlow 0.7.30: проверка русскоязычных источников

Источник: https://github.com/fmhy/edit/blob/main/docs/audio.md
и https://github.com/fmhy/edit/blob/main/docs/non-english.md.
FMHY публикует справочник ссылок, **не предоставляет единый музыкальный API**,
и сам по себе не разрешает перепубликацию или передачу песен третьему плееру.

| Сайт | Проверка 21.11.2026 | Решение |
| --- | --- | --- |
| [Tancpol](https://tancpol.net/) | Есть в FMHY как Russian Music; прямое обращение к сайту дало HTTP 403. Официальный публичный API и разрешение интеграции не подтверждены | **Не добавлять** |
| [z3.fm](https://z3.fm/) | Сайт доступен: список треков, пользовательские записи, поиск и веб-плеер. Документированного разрешённого API для стороннего плеера не обнаружено | **Не добавлять** |
| [Russian Records](https://www.russian-records.com/) | Архив русских исторических записей, сайт запросил CAPTCHA; стабильный API публичного аудиопотока не подтверждён | **Не добавлять** |
| OnlineRadioBox, Top Radio, Radio Garden | Каталоги радио, отдельных песен через открытый аудио API не предоставляют по имеющимся данным | Только как дополнительные справочные источники |
| [Radio Browser](https://docs.radio-browser.info/) | Документированы поиск по `countrycode`, `url_resolved`, `hidebroken`, `lastcheckok` | **Внедрён отдельной вкладкой** |

Вкладка «Русское радио» фильтрует `countrycode = RU`,
`lastcheckok = 1`, выполняет поиск по названию, сохраняет избранные
станции и воспроизводит поток через Media3. Текущий онлайн-статус
каталога не гарантирует безошибочного воспроизведения на каждом устройстве.
Некоторые станции вещают по HTTP; существующее Android cleartext-разрешение
сохранено для совместимости с пользовательскими потоками.

Отдельно добавлены синхронизированные тексты LRCLIB, локальная история,
восстановление очереди/позиции, повтора и перемешивания и ручная кнопка
переключения уже найденного запасного потока. **Audius, Jamendo и VK
не включены.**

Новый официальный релиз **не опубликован**. Для релиза нужна проверка
компиляции, Media3 на телефоне, совпадение подписи и проверка Play Protect.
