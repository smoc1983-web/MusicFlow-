# MusicFlow Cinema URL TEST v4

**Это только отдельный тест**. Официальную MusicFlow v0.7.40 и Pro-ветки не изменяем.

## Что изменено
- На странице «Кино» больше **нет демо-фильмов, тестовых подборок, плагинов, Lampa WebView и установки JS-расширений**.
- Единственная точка добавления: **Кино → + Источник → HTTPS-ссылка → Добавить**.
- Можно подключить страницу конкретного фильма `.html`, прямой MP4/HLS/DASH, M3U-плейлист или JSON-каталог по URL. Форматы выбираются автоматически по URL.
- Для HTML-страниц обрабатываются **только открытые OpenGraph-метаданные** и явные `<video>`, `<source>`, `og:video` ссылки. Не выполняется чужой JavaScript, не исследуются скрытые токены плееров и не обходятся ограничения.
- Первый источник при первоначальном запуске: **Заводчица (2026)** — `https://ff.sanfilm2.link/69359-zavodchica-2026.html`. Это начальная ссылка, а не встроенный видеоролик.
- Если сайт недоступен / выдаёт 403 или содержит только iframe/JS-плеер, отображается карточка с диагностикой **без ложной кнопки «Смотреть»**. Прямая видеоссылка не подтверждена.
- Найденный прямой поток открывается собственным **Media3-плеером внутри страницы «Кино»**. Сохранение позиции, поиск, избранное и удаление ссылок остаются.
- Ссылка сохраняется даже если удалённый сервер временно не отвечает; кнопку обновления можно использовать для повторной проверки.
- Данные этой тестовой сборки не смешиваются с официальной MusicFlow и прежними Cinema TEST.

## Установка
APK: `com.musicflow.preview.cinematest4`, ярлык **MusicFlow Кино URL TEST**. Debug-подпись только для испытаний. Официальная подпись и релиз — после проверки пользователя.

## Проверка
1. Установить рядом с основной MusicFlow.
2. Открыть «Кино» — должна быть карточка «Заводчица (2026)» и сохранённый URL.
3. Если сервер недоступен, увидеть причину, а не бесконечное ожидание/фиктивное видео.
4. Добавить другую HTTPS-ссылку на фильм, прямой MP4/HLS или M3U; проверить появление карточки.
5. При наличии явного совместимого потока нажать «Смотреть» — видео должно играть внутри страницы.
6. Проверить поиск, избранное, обновление и удаление источников.

**Ограничение проверки:** указанная страница Sanfilm на момент подготовки не ответила при внешнем открытии. Наличие её прямого MP4/HLS на реальном устройстве не подтверждено. Приложение не обходит DRM, платные доступы или блокировки. Используйте только разрешённые к воспроизведению источники.
