# Cinema LAB v2 — Lampa JS integration (isolated TEST APK)

**Do not merge into official MusicFlow, and do not sign/publish an official update yet.** This branch is exclusively for testing.

### Android install
- New app ID: `com.musicflow.preview.cinematest2` (debug signing).
- Display name: **MusicFlow Кино Lampa TEST**.
- Coexists with official MusicFlow and previous Cinema TEST. Different data stores.
- The test launches into the Cinema tab; new button **Lampa · JS** opens a separate Lampa browser environment.

### Lampa plugins
The test embeds the **official Lampa web client** at `https://yumata.github.io/lampa/` in a WebView, with an optional HTTP `http://lampa.mx/` fallback that is explicitly marked HTTP. It uses the existing upstream **`Lampa.Plugins.add({url, status:1})`** API, which loads JavaScript in the Lampa web runtime. Users can install by tapping **Lampa · JS → JS → URL → Разрешить и добавить**. The initial URL is `http://bwa.ad/rc` for explicit user testing.

This is a real Lampa runtime, **not** an attempt to parse Lampa JavaScript in Media3. Sources/playback provided by the plugin are handled by Lampa itself and its available web players. The app does **not** promise native streaming interoperability, downloads, or access to unavailable paid content.

**Security:** no `addJavascriptInterface`, no native bridge, file access off, no runtime code in Kotlin, page navigation limited to the selected Lampa origin. User must explicitly confirm each JS plugin. Plugins can still access Lampa's web storage and communicate over the network. **HTTP plugin URLs are insecure and may be blocked by HTTPS mixed-content rules**; try the provider's official HTTPS URL where available. A registered Lampa plugin is not proof it loaded successfully; test its appearance/function inside Lampa. Never enter passwords or payment details in untrusted plugins.

### HTTP 403 fix/test
External copies of Blender films hosted by Google may answer **HTTP 403**; the app cannot grant access to those servers. Instead:
- A genuine **8-second local diagnostics MP4** is generated by GitHub Actions and packaged in `assets/cinema_lab_test.mp4`.
- A **«Проверка видео · офлайн»** card plays this MP4 without any network.
- If the remote Blender demo video fails with HTTP 403, the player **explicitly displays a warning** and switches to the same diagnostic clip; this is never represented as playing the requested film.
- Do not ship a misleading expired/forbidden link as guaranteed working film playback.

### Test checklist
1. Install APK alongside existing MusicFlow and Cinema TEST.
2. Open cinema; choose **«Проверка видео · офлайн»**. A moving image and sound should start.
3. Open **Elephants Dream**. If server returns 403, expect a visible fallback warning + short technical clip.
4. Tap **Lampa · JS** and wait for web Lampa to load.
5. Tap **JS**, inspect or enter `http://bwa.ad/rc`, confirm. Check Lampa's extension menu. Note: plugin loading may fail due to provider reachability, certificate, content policy or mixed content; the test reports registration separately.
6. Test back, source switch, retry and app restart. Check that official MusicFlow and its data remain untouched.
